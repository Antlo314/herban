# Herban Alchemy

Organic skincare e-commerce website for Herban Alchemy — a bougetto beauty brand focused on clean, luxurious body care for melanated skin.

**Live Preview**: Open `index.html` in a browser (static site).

## Features
- Fenty-inspired layout: clean white + black base with vibrant, colorful, lively photography and content
- Two hero products with many scent variations (like Crowned Skin focus):
  - Luxury Body Butter Glaze
  - Full Body Fragrance Oil
- Working shopping cart (JavaScript + localStorage)
- Interactive "Find Your Scent" quiz
- Responsive, modern design using Tailwind CSS (CDN)
- Product assets and logo from client

## Pages
- `index.html` — Homepage with hero, product highlights, quiz teaser, cart
- `shop.html` — Full shop with filters and scent selectors
- `about.html` — Brand story
- `ingredients.html` — Key ingredients education

## Tech
- Pure static HTML + Tailwind via CDN + vanilla JS
- No build step required — just open the HTML files

## Client Requirements Incorporated
- From intake form + latest feedback
- Fenty layout energy + colorful vibrant photos
- White with black accents (not earthy)
- Focused on Body Butter Glaze + Body Oil with scent variations
- Logo and visuals from herban2.0 folder
