AI Theme & Image Generator

Cohesively brand your storefront using AI-designed palettes and image generation.

Generate Cohesive Theme Vibe Vibe Generator Help: Type in a descriptive, sensual atmosphere. The AI will write custom HSL-colored CSS rules, font systems, matching advertising banner copy, and specific visual prompts for you.

Enter a descriptive mood or sensory vibe for your brand (e.g. "A cozy vanilla orchid campfire night, warm and sweet, natural wood highlights" or "A refreshing eucalyptus mint spa ritual, clean silver and sage"). The AI will dynamically design the entire storefront look and feel:

  • Color Palette: Designs matching Primary, Accent, Background, and Text colors.
  • Typography Pairing: Selects a font system (e.g. Playfair + Inter, Lora + Outfit, or clean Outfit) that fits the aesthetic.
  • AI Image Prompts: Creates customized high-end prompts for all 3 image slots (Hero Background, Quiz BG, and Journal Featured Image).
  • Themed Copywriting: Writes matching hero copy (Badge, Title, Subtitle, Description, CTA Buttons) and announcement banner/footer text to make the brand's voice match the visuals!

Tip: Vibe generation updates inputs across both the "AI Theme & Images" and "Brand Settings" tabs. Review and tweak them, then click Save on either tab to apply.

How to Connect Your API Keys

Why do we need this? The API keys are used securely on your backend server. They power the interactive AI Skincare Guide chat widget (Aura) on the storefront and the AI Theme/Image generators in this admin control center.

Google Gemini Option A: Gemini API Key (Recommended)

Google Gemini provides a free tier with very fast speeds, making it the ideal selection for standard storefronts.

  1. Visit the Google AI Studio console.
  2. Log in with any normal Google/Gmail account.
  3. Click the prominent "Get API key" button in the top left sidebar.
  4. Click "Create API key", select standard terms, and click "Create API key in new project".
  5. Copy the generated code string (starts with AIzaSy...).
  6. Paste it into the Google Gemini API Key field in the Chatbot settings page and click Save.

OpenAI ChatGPT Option B: OpenAI API Key

If you prefer OpenAI's models (ChatGPT & DALL-E), you can configure a standard OpenAI platform developer key.

  1. Go to the OpenAI Developer Platform .
  2. Sign up or log in.
  3. Go to Settings -> Billing and add a payment method, topping up at least $5.00 in credits (OpenAI API key requires a positive credit balance to function).
  4. Click "API Keys" in the left sidebar, and click "Create new secret key".
  5. Copy the resulting key string (starts with sk-...).
  6. Paste it into the OpenAI ChatGPT API Key field, then save.
